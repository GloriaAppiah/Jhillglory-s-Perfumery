# Jhillglory's Perfumery

## Project Overview

**Project Title:** Jhillglory's Perfumery
**Industry:** Perfume / Beauty
**Business:** Jhillglory's Perfumery
**Project Type:** Local Business Landing Page

Jhillglory's Perfumery is a simple one-page website created for a fictional perfume business. The website introduces the business, displays its products and services, explains how customers can order, and provides a way for customers to get in touch.

The main goal of the website is to give customers an attractive and easy-to-use place to explore fragrances and learn more about the business.

## Target Customers

The website is designed for people who are interested in perfumes, body splashes, fragrances, and gift packages.

## Features

The website contains the following sections:

* **Home/Hero Section** – Introduces Jhillglory's Perfumery and encourages visitors to view the fragrances.
* **Our Services** – Shows the main products and services offered by the business.
* **How We Work** – Explains the process customers follow when choosing and ordering products.
* **Recent Work** – Displays examples of perfumes and fragrance products.
* **Contact Us** – Provides a form where visitors can enter their name, email, and message.
* **Footer** – Contains the business name and useful information.

### JavaScript Interaction

JavaScript was used to add interaction to the website.

The website includes:

1. **Hamburger Navigation Menu** – On smaller screens, users can open and close the navigation menu.
2. **Contact Form Validation** – The form checks that the required fields have been completed and gives the user feedback.
3. **Form Confirmation** – After the form is successfully completed, a confirmation message is displayed.

The contact form is a demonstration and does not send messages to an actual email service.

## Build Process

I completed the project using the following steps:

1. Selected a perfume business as my local business.
2. Planned the sections and content for the landing page.
3. Researched website designs for inspiration.
4. Created the HTML structure.
5. Added the navigation menu and six required sections.
6. Added relevant perfume images.
7. Styled the website using CSS.
8. Added JavaScript for the navigation menu and contact form.
9. Tested the website and fixed layout and navigation issues.
10. Added mobile responsiveness using CSS media queries.
11. Created the README documentation.
12. Uploaded the project to GitHub.

## Testing

I tested the website to make sure:

* Navigation links move to the correct sections.
* The hamburger menu opens and closes correctly.
* The contact form checks for empty fields.
* The contact form displays a confirmation message.
* Images display correctly.
* Buttons and links work correctly.
* The website layout works on a laptop.
* The website adjusts to smaller screen sizes.

### Mobile Responsiveness

Mobile responsiveness was completed using CSS media queries.

I tested the layout at different screen sizes to make sure that the content does not overlap and that the navigation, cards, images, and contact form remain usable.

## Challenge I Solved

One of the challenges I faced was getting the navigation and hamburger menu to display correctly. I had some CSS rules that conflicted with each other, so I cleaned up the CSS and adjusted the navigation styling.

I also worked on making the website responsive so that the layout could adapt to smaller screens.
